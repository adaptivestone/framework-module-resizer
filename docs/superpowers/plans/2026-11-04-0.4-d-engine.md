# 0.4.0 Phase D: the image engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Resizing and encoding go through a public `ImageEngine` port, host steps see only pixels, and the default `SharpEngine` writes the same files as 0.3.0 (design rulings D1 to D8).

**Architecture:** `src/render.ts` and `src/processor.ts` stop touching Sharp. Every pixel operation after the decode is `engine.resize` or `engine.encode` on a `Raster`. `SharpEngine` (`src/engines/sharp.ts`) holds the chain `render.ts` holds today, and `src/engines/sharpRaster.ts` holds the public helpers `rasterToSharp` and `sharpToRaster`. `VariantStep` takes and returns a `Raster`, like `BeforeStep`. The order: pin the output on untouched code, move the chain behind the seam with that pin green, change the step form, open the option, then prove it on an engine with no Sharp.

**Tech Stack:** Node >= 24, TypeScript with type stripping, `node:test`, Biome, Sharp 0.35.

**Spec:** `docs/design/2026-11-04-0.4.0.md`, rulings D1 to D8. Research: `.superpowers/sdd/2026-11-04-0.4.0/research/research-engine.md` and its prototype `.superpowers/sdd/2026-11-04-0.4.0/research/engine-proto.tgz`. The rulings below overrule the research where they differ.

## Rulings

1. **`ResizeRequest` gains an optional `coverBox`.** `reduceToBox` asks for the exact size and passes the box it was computed from, and `SharpEngine` then uses `fit: 'outside'` on that box. Why: the research's claim that `fill` at the computed size gives the same bytes is wrong when a side rounds, because `fill` scales each axis by its own factor. An identity `beforeStep` with `{ width: 620 }` on a 1024×683 JPEG wrote different bytes. With the hint, 196 compared previews match 0.3.0. Sharp rounds exact halves its own way, so a `coverBox` result may differ from the computed size by a pixel: `resized()` accepts a result within a pixel of it that covers the box, and keeps Sharp's size. Measured: 4000×3000 with `{ width: 1125 }` comes back 1126×844 where the arithmetic says 1126×845, and an exact check loses every preview of that media. If wrong: one optional field on a 0.x contract, which any other engine ignores.
2. **Bytes are pinned, by comparison in one process, never by stored hashes.** `src/previewBytes.test.ts` spells out the 0.3.0 Sharp chain and compares its bytes with what `generate()` uploads. Why: both sides run on one Sharp, so an upgrade moves them together, which answers the brittleness worry. Measured: it passes on 0.3.0, passes on the seam, and fails on the seam without ruling 1. The `encodeSig` vectors stay in `src/signatures.test.ts`. If wrong: a deliberate output change must also edit the chain in that test.
3. **`SharpEngine.formats` is a fixed table of every id `toFormat` accepts, filtered by `sharp.format[entry].output.buffer`.** On the prebuilt binaries: `jpeg, jpe, jpg, png, webp, tiff, tif, gif, heif, heic, avif, dz, tile, raw`. Why: `output.alias` is incomplete, and a global libvips reports outputs `toFormat` refuses; `raw`, `dz`, `tile` and `heic` are listed because they write today, and D7 wants no new refusal for what works. A test parses Sharp's own refusal and checks both ways. If wrong: a Sharp upgrade that adds an id fails that test until the table grows.
4. **`verify()` compares ids exactly, so an upper-case `JPG` is refused**, though Sharp lower-cases it. Why: `engine.formats` stays a plain list, `animatedFormats` is matched exactly too, and SharpEngine cannot list every case. If wrong: a host with `formats: ['JPG']` renames it and regenerates; the changelog names this.
5. **`verify()` checks `formats` and every `encode.formats` key the host wrote or changed.** A key outside `formats` whose options still deep-equal the package default is exempt (`isDeepStrictEqual` against the default config). Why: a per-call `formats` can ask for any key, but the package's own default entry is no request of the host's: on a build without HEIF, `formats: ['jpeg', 'webp']` works on 0.3.0 and must keep working, and an engine writing webp with `formats: ['webp']` must not hear of `jpeg` and `avif`, which the host never wrote (this overturns the first form of this ruling in part, on review of Task 4). If wrong: a per-call `formats: ['avif']` on such a build fails at render, as on 0.3.0, not at `verify()`; a host that keeps an unused `jxl` entry on a build without it still removes that entry.
6. **The pin lands first, as its own task on untouched code.** Why: every later commit is then checked against 0.3.0 with no chance of the test adapting to the change. If wrong: one small extra commit.
7. **`src/raster.ts` is split into `src/helpers/raster.ts` (`rasterProblem`, `checkRaster`, no Sharp) and `src/engines/sharpRaster.ts`.** Why: `processor.ts` needs `checkRaster` without reaching Sharp. If wrong: nothing for hosts; the main entry exports the same names.
8. **`planRules` takes a required fourth argument, `animatedFormats`,** so `plan.ts` holds no knowledge of an engine. If wrong: two test call sites and the bench.
9. **Task 2 keeps Sharp-form variant steps for one commit** (`rasterToSharp` / `readRaster` in `render.ts`) and still reads channels before the steps, as 0.3.0 does. Why: the whole gate stays green and D1's break sits in one reviewable commit. If wrong: `render.ts` imports a Sharp helper for one commit.
10. **`createDecoderSet` is not split.** The no-Sharp proof hands the Processor a small decoder set of its own. Why: D6, and a Sharp-free install is a non-goal. If wrong: `new Resizer` still loads Sharp, which the design accepts.
11. **`encode` results get checks beyond the research.** `format` must match `/^[a-z0-9]+$/i`, because it becomes the file extension; `data` must not be empty; `contentType` must match `/^image\/[a-z0-9.+-]+$/i`; the size must equal the raster's, because hosts read it through `formatPictureUrls`; and the refusal `RESIZE_SVG_PUBLIC_PREVIEW` fires on a `contentType` starting `image/svg` and on a `format` matching `/^(svgz?|x?html?|xml)$/i`. Why: a custom engine can return a MIME type in `format`, an empty file, or mislabel SVG. These are guards against a mislabelled file, not a boundary: an engine is host code. Every `SharpEngine` row was measured safe (jpeg, png, webp, avif, gif, tiff, raw, dz and their aliases at 1 to 4 channels, animated webp and gif, `heif`/`heic` with `compression: 'av1'`). No render-time format check: `JPG` works through Sharp without `verify()` (ruling 4), so `encode` must refuse a format it does not write, and only `verify()` compares the list. If wrong: an engine with an unusual extension or content type is refused.
12. **`RESIZE_ENGINE_INVALID` and `RESIZE_ENGINE_FORMAT_UNSUPPORTED` are `ResizeSetupError`, `retryable: true`.** Why: A5, since a rolling deploy can bring a fixed engine. `RESIZE_SVG_PUBLIC_PREVIEW` keeps the `retryable: true` phase A gave it, for the same reason: only a custom engine reaches it now. If wrong: a task on a broken engine retries until its dead-letter.
13. **The engine check at construction also requires a non-empty `formats`, and `verify` to be a function when given; `animatedFormats` may be empty; only `undefined` means the default.** The `verify()` message names the Resizer. Why: fail where the mistake is, and a process can hold several Resizers. If wrong: nothing a working engine would notice.
14. **`EngineCallOptions` carries the task's `signal`; `SharpEngine` ignores it,** because a Sharp call cannot be cancelled and `limits.processingTimeoutSeconds` bounds it. Why: another engine may be able to cancel. If wrong: one unused field.
15. **Messages stop saying "Sharp format ids".** Why: they would mislead a host on another engine. If wrong: a log grep on the old words, in a 0.x release.
16. **`straightAlpha` keeps two channels on grey with alpha,** where Sharp's read-back returned four. Why: `encode` takes 1 to 4 channels and `renderSize` makes colour when channels are below 3. If wrong: only rasters a host decoder marks are affected.
17. **`docs/host-adoption.md` is not edited.** Why: phase F builds `UPGRADING.md` from the changelog, and that file does not ship (`files` holds `dist` and `AGENTS.md`). If wrong: it keeps saying "`variantSteps` keep their Sharp instance" until phase F.
18. **Rewritten steps can write different files on new previews only, because a step now runs before the flatten and steps chain — the new order is what D1 implies, the watermark case is unchanged, and keeping 0.3.0's order would need a third engine method, which D8 avoids — cost: a host with a non-composite step must look at its first new previews.** Measured limit of "the watermark case is unchanged", against a real 0.3.0: one `composite` writes the same bytes on an opaque source (for the default flatten list: with `png` added to `flatten.formats` it writes RGB where 0.3.0 wrote RGBA, with no pixel difference), on a transparent source with a straight edge when the overlay does not touch those pixels, and on every format that keeps alpha. On a flattened format, a transparent source can move wherever the preview has partly transparent pixels, at most 2 levels before the JPEG encoder, up to 20 of 255 measured in the JPEG, because the overlay used to land after the flatten. Task 3 pins both, and the changelog and README say so.
19. **`rasterToSharp` applies `limits.processingTimeoutSeconds` to a raster the core handed to a variant step, through a `WeakMap` keyed by the raster object, because stuck Sharp calls hold libuv's threads and starve healthy tasks — this reverses the ruling of Task 2's review, that a step's Sharp work is unbounded — cost: a host chain that needs longer adds its own `.timeout()`.** Measured with 4 slow variants and one healthy task at `taskTimeoutMs` 2000 and `maxAttempts` 3: on 0.3.0 at a limit of 1 s the healthy task completed in 1515 ms; with no limit it was dead after 11820 ms, 3 attempts, 0 previews. The `Raster` shape does not change. The render loop registers each raster it hands to a variant step. A raster read back through `sharpToRaster` from a chain on such a raster carries the limit too, through a second `WeakMap` keyed by the Sharp instance, so a second chain in one step stays under it: a variant holds a thread for at most (chains + 1) × the limit, each chain and the encode having their own. A chain's own `.timeout({ seconds })` replaces the limit on that chain, `{ seconds: 0 }` turns it off there, and a raster spread into a new object or built by the host, a fresh `sharp()`, and a `rasterToSharp` from a duplicate copy of the package have none. `beforeSteps` stay unbounded, as on 0.3.0. Sharp work the host runs itself and any other host code in a step are unbounded, can starve other tasks and dead-letter healthy ones, and a timed-out delivery keeps its memory until the running step ends: the docs say so. The signal is checked between steps, so a stopped task's remaining steps and encode do not run (`RESIZE_TASK_ABORTED`, retryable, on the variant's warning); a variant past its steps can still store its row.
20. **A step result whose `info.format` is `'raw'` is Sharp's own output from `toBuffer({ resolveWithObject: true })`, whose `premultiplied` flag lies after a resize: the flag is dropped, on both kinds of step.** Why: `straightAlpha` otherwise divides straight bytes, with no error ([200,100,50,128] stored as [255,193,94,128]). A raster a step built has no `format`, and its flag is believed. Cost: new previews of a `beforeStep` that returned it change too; it shifted colours on 0.3.0 as well (measured: [255,197,97,128]), and stored previews stay until the pipeline's `version` is bumped.

`src/previewBytes.test.ts`:

```ts
// The files a render writes. Each case spells out, with Sharp itself, the chain that wrote the files
// of 0.3.0, and compares its bytes with what `generate()` uploads. Both sides run in one process on
// one Sharp, so a Sharp upgrade moves them together: this fails only when the module's chain changes.
import assert from 'node:assert/strict';
import { afterEach, test } from 'node:test';
import sharp, { type FormatEnum, type OutputOptions, type Sharp, type SharpOptions } from 'sharp';
import type { DecodeBox, Raster, RasterInfo } from './contracts/decoder.ts';
import type { Pipeline } from './contracts/pipeline.ts';
import { SharpDecoder } from './decoders/sharp.ts';
import { Resizer, resetResizerForTests } from './resizer.ts';
import { fakeMedia, memoryStorage } from './testHelpers/fakes.ts';
import { makeImageConfig } from './testHelpers/resizeConfig.ts';
import type { MediaLike, Preview, SizeInput } from './types.d.ts';

sharp.concurrency(1); // AVIF bytes depend on the thread count; a test file has its own process
afterEach(resetResizerForTests);

const config = makeImageConfig({
  animated: true,
  formats: ['jpeg', 'webp', 'png', 'avif'],
  encode: {
    formats: {
      jpeg: { quality: 88, mozjpeg: true, chromaSubsampling: '4:2:0' },
      webp: { quality: 82, effort: 2 },
      png: {},
      avif: { quality: 64, effort: 2 },
      gif: {},
    },
  },
});
const { limits, encode } = config;
const timeout = { seconds: limits.processingTimeoutSeconds };
const ALL = ['jpeg', 'webp', 'png', 'avif'];
const STILL = ['jpeg', 'webp'];

interface Geometry {
  width: number;
  height: number;
  fit: 'fill' | 'cover';
  sharpen: boolean;
}

const input = ({ data, info }: Raster): [Buffer, SharpOptions] => {
  const { width, height, channels, frames = 1 } = info;
  const raw = { width, height: height * frames, channels, ...(frames > 1 ? { pageHeight: height } : {}) };
  return [data, { raw, limitInputPixels: width * height * frames }];
};

async function rawOf(img: Sharp): Promise<Raster> {
  const { data, info } = await img.timeout(timeout).raw({ depth: 'uchar' }).toBuffer({ resolveWithObject: true });
  return { data, info: { width: info.width, height: info.height, channels: info.channels as RasterInfo['channels'] } };
}

function resizedAsBefore(frame: Raster, g: Geometry): Promise<Raster> {
  const img = sharp(...input(frame)).resize(g.width, g.height, { fit: g.fit, position: 'center' }).toColorspace('srgb');
  return rawOf(g.sharpen ? img.sharpen() : img);
}

function encodedAsBefore(raster: Raster, format: string): Promise<Buffer> {
  const { channels, frames = 1, delay, loop } = raster.info;
  const img = sharp(...input(raster));
  const flat = (channels === 2 || channels === 4) && encode.flatten.formats.includes(format);
  const options = { ...(frames > 1 ? { delay, loop } : {}), ...encode.formats[format] } as OutputOptions;
  return (flat ? img.flatten({ background: encode.flatten.background }) : img)
    .toFormat(format as keyof FormatEnum, options)
    .timeout(timeout)
    .toBuffer();
}

/** Fixed photo-like pixels: gradients and a little noise; the fourth channel is half transparent. */
function pixels(width: number, height: number, channels: 1 | 3 | 4): Buffer {
  const data = Buffer.alloc(width * height * channels);
  let seed = 12345;
  for (let i = 0; i < data.length; i++) {
    const c = i % channels;
    const x = Math.floor(i / channels) % width;
    const y = Math.floor(i / channels / width);
    seed = (seed * 1103515245 + 12345) & 0x7fffffff;
    data[i] = c === 3 ? (x < width / 2 ? 128 : 255) : 128 + 60 * Math.sin(x / 17 + c) + 50 * Math.cos(y / 23 - c) + ((seed >> 16) & 15);
  }
  return data;
}
const image = (width: number, height: number, channels: 1 | 3 | 4): Sharp =>
  sharp(pixels(width, height, channels), { raw: { width, height, channels } });

/** What generate() uploads, by `sizeKey:format`. */
async function uploaded(body: Buffer, sizes: SizeInput[], formats: string[], pipeline: Pipeline = {}) {
  const { storage, files } = memoryStorage();
  const doc: MediaLike = { id: 'm1', previews: [] };
  const resizer = new Resizer({
    storage,
    media: fakeMedia({ load: async () => doc, appendPreviews: async (_id: string, rows: Preview[]) => rows }),
    config,
    logger: { info() {}, warn() {}, error: console.error },
    pipelines: { default: pipeline },
  });
  doc.original = await resizer.uploadOriginal({ body, visibility: 'private' });
  const { created, failed } = await resizer.generate({ media: doc, sizes, formats });
  assert.equal(failed, 0);
  return new Map(created.map((row) => [`${row.sizeKey}:${row.format}`, files.get((row.storageRef as { key: string }).key) as Buffer]));
}

async function decoded(bytes: Buffer, box: DecodeBox, frames = 1): Promise<Raster> {
  const decoder = new SharpDecoder();
  return decoder.render(bytes, box, { limits, source: await decoder.inspect(bytes, limits), frames });
}

async function assertSame(files: Map<string, Buffer>, key: string, raster: Raster, formats: string[]) {
  for (const format of formats) {
    const actual = files.get(`${key}:${format}`);
    assert.ok(actual, `no file for ${key}:${format}; have ${[...files.keys()].join(' ')}`);
    const expected = await encodedAsBefore(raster, format);
    assert.ok(actual.equals(expected), `${key}:${format}: ${actual.length} bytes differ from the chain's ${expected.length}`);
  }
}

const fill = (width: number, height: number): Geometry => ({ width, height, fit: 'fill', sharpen: true });
const cover = (width: number, height: number): Geometry => ({ width, height, fit: 'cover', sharpen: true });

test('no steps, a JPEG: width, height, cover and fit sizes', async () => {
  const bytes = await image(1024, 683, 3).jpeg({ quality: 90 }).toBuffer();
  const files = await uploaded(bytes, [{ width: 320 }, { height: 199 }, { width: 200, height: 200 }, { fit: true }], ALL);
  const base = await decoded(bytes, { width: 1024, height: 683 });
  await assertSame(files, '320w', await resizedAsBefore(base, fill(320, 213)), ALL);
  await assertSame(files, '199h', await resizedAsBefore(base, fill(298, 199)), ALL);
  await assertSame(files, '200x200', await resizedAsBefore(base, cover(200, 200)), ALL);
  await assertSame(files, 'fit', base, ALL);
});

test('no steps, one small size: the decoder shrinks to its box', async () => {
  const bytes = await image(1024, 683, 3).jpeg({ quality: 90 }).toBuffer();
  const files = await uploaded(bytes, [{ width: 620 }], STILL);
  await assertSame(files, '620w', await resizedAsBefore(await decoded(bytes, { width: 621, height: 414 }), fill(620, 414)), STILL);
});

test('no steps, a transparent PNG: JPEG is flattened, the others keep alpha', async () => {
  const bytes = await image(640, 480, 4).png().toBuffer();
  const files = await uploaded(bytes, [{ width: 320 }, { width: 200, height: 200 }, { fit: true }], ALL);
  const base = await decoded(bytes, { width: 640, height: 480 });
  await assertSame(files, '320w', await resizedAsBefore(base, fill(320, 240)), ALL);
  await assertSame(files, '200x200', await resizedAsBefore(base, cover(200, 200)), ALL);
  await assertSame(files, 'fit', base, ALL);
});

test('no steps, a grey PNG comes out as colour', async () => {
  const bytes = await image(640, 480, 1).png().toBuffer();
  const files = await uploaded(bytes, [{ width: 320 }], STILL);
  await assertSame(files, '320w', await resizedAsBefore(await decoded(bytes, { width: 320, height: 240 }), fill(320, 240)), STILL);
});

test('no steps, a small source keeps its own size and is not resized', async () => {
  const bytes = await image(150, 100, 3).jpeg({ quality: 90 }).toBuffer();
  const files = await uploaded(bytes, [{ width: 300, height: 300 }], STILL);
  await assertSame(files, '300x300', await decoded(bytes, { width: 150, height: 100 }), STILL);
});

test('no steps, an animation: WebP and GIF keep the frames, JPEG gets the first', async () => {
  const frame = (red: number): Buffer => {
    const data = pixels(64, 48, 3);
    for (let i = 0; i < data.length; i += 3) {
      data[i] = red;
    }
    return data;
  };
  const stack = Buffer.concat([frame(255), frame(128), frame(0)]);
  const bytes = await sharp(stack, { raw: { width: 64, height: 144, channels: 3, pageHeight: 48 } }).gif({ delay: [100, 200, 300], loop: 3 }).toBuffer();
  const files = await uploaded(bytes, [{ width: 32 }], ['webp', 'gif', 'jpeg']);
  const base = await decoded(bytes, { width: 32, height: 24 }, 3);
  const { width, height, channels, delay, loop } = base.info;
  const frameBytes = width * height * channels;
  const frames: Raster[] = [];
  for (let i = 0; i < 3; i++) {
    const data = base.data.subarray(i * frameBytes, (i + 1) * frameBytes);
    frames.push(await resizedAsBefore({ data, info: { width, height, channels } }, fill(32, 24)));
  }
  const animated = { data: Buffer.concat(frames.map((f) => f.data)), info: { ...frames[0].info, frames: 3, delay, loop } };
  await assertSame(files, '32w', animated, ['webp', 'gif']);
  await assertSame(files, '32w', frames[0], ['jpeg']);
});

test('beforeSteps: the reduction to the box scales both axes by one factor', async () => {
  const identity = { beforeSteps: [async (r: Raster) => r] };
  const wide = await image(1024, 683, 3).jpeg({ quality: 90 }).toBuffer();
  let files = await uploaded(wide, [{ width: 620 }], STILL, identity);
  let source = await decoded(wide, { width: 1024, height: 683 });
  let reduced = await rawOf(sharp(...input(source)).resize(621, 414, { fit: 'outside' }).toColorspace('srgb'));
  await assertSame(files, '620w', await resizedAsBefore(reduced, fill(620, 414)), STILL);

  resetResizerForTests();
  const large = await image(1200, 800, 3).jpeg({ quality: 90 }).toBuffer();
  files = await uploaded(large, [{ width: 3, height: 199 }], ['webp'], identity);
  source = await decoded(large, { width: 1200, height: 800 });
  reduced = await rawOf(sharp(...input(source)).resize(299, 199, { fit: 'outside' }).toColorspace('srgb'));
  await assertSame(files, '3x199', await resizedAsBefore(reduced, cover(3, 199)), ['webp']);
});

test("beforeSteps: a side Sharp's outside fit rounds its own way keeps Sharp's size", async () => {
```

```ts
// The image engine: the two pixel operations the core needs after a decode. A Raster goes in, and
// a Raster or a preview's bytes come out, so nothing here names an image library.
import type { ResizeLimits } from '../types.d.ts';
import type { DecodeBox, Raster } from './decoder.ts';

export interface EngineCallOptions {
  limits: ResizeLimits;
  signal?: AbortSignal; // the task's; an engine that cannot cancel ignores it
}

export interface ResizeRequest {
  width: number; // the exact output size: the engine never picks one
  height: number;
  mode: 'fill' | 'cover'; // fill: the whole frame into this size. cover: scale to cover it, centre crop
  sharpen: boolean; // an engine without a sharpener ignores it
  /**
   * Set only on the reduction after `beforeSteps`: the box `width × height` was computed from, by
   * one factor for both axes. An engine that takes a box scales more exactly from it; any other
   * ignores it and returns `width × height`.
   */
  coverBox?: DecodeBox;
}

export interface EncodeRequest {
  format: string; // a configured id, as the host wrote it
  options: Record<string, unknown>; // encode.formats[format]
  background?: string; // when set, flatten the raster onto this colour first
}

export interface EncodedImage {
  data: Buffer;
  format: string; // the preview's file extension: letters and digits
  contentType: string;
  width: number;
  height: number; // of one frame
}

/**
 * Resizes and encodes. Extend this, or write any object of the same shape: the core never checks
 * `instanceof`. Two rules the types cannot state. An engine must not write to its inputs, because
 * the formats of one size share one raster. It must be re-entrant, because calls run concurrently,
 * up to `config.concurrency`.
 */
export abstract class ImageEngine {
  abstract readonly id: string; // names the engine in messages
  abstract readonly formats: readonly string[]; // what encode writes; verify() checks the config against it
  abstract readonly animatedFormats: readonly string[]; // what encode writes with every frame
  /** One frame in; one frame out at exactly the size asked for (with `coverBox`: within a pixel of it, covering the box), 8-bit sRGB, 3 channels or 4 with alpha. */
  abstract resize(frame: Raster, req: ResizeRequest, opts: EngineCallOptions): Promise<Raster>;
  /** One frame (1 to 4 channels, straight alpha), or `info.frames` of them for an animated format. */
  abstract encode(raster: Raster, req: EncodeRequest, opts: EngineCallOptions): Promise<EncodedImage>;
  verify?(): void | Promise<void>;
}
```

```ts
// The built-in engine: libvips through Sharp, as render.ts called it in 0.3.0. A Sharp call cannot
// be cancelled, so the signal is not watched: `limits.processingTimeoutSeconds` bounds every call.

// Every id Sharp's toFormat() accepts, under the `sharp.format` entry that says whether this build
// writes it to a Buffer. A fixed table, because `output.alias` is incomplete and a global libvips
// reports outputs toFormat() refuses. Aliases are listed: a host with `formats: ['jpg']` works
// today, and renaming it would regenerate its previews.
const TO_FORMAT_IDS: Readonly<Record<string, readonly string[]>> = {
  jpeg: ['jpeg', 'jpe', 'jpg'],
  png: ['png'],
  webp: ['webp'],
  tiff: ['tiff', 'tif'],
  gif: ['gif'],
  heif: ['heif', 'heic', 'avif'],
  dz: ['dz', 'tile'],
  raw: ['raw'],
  jp2: ['jp2', 'jpx', 'j2k', 'j2c'],
  jxl: ['jxl'],
};

function writableIds(): string[] {
  const available = sharp.format as unknown as Record<string, { output?: { buffer?: boolean } } | undefined>;
  return Object.entries(TO_FORMAT_IDS)
    .filter(([entry]) => available[entry]?.output?.buffer === true)
    .flatMap(([, ids]) => ids);
}

export class SharpEngine extends ImageEngine {
  readonly id = 'sharp';
  readonly formats: readonly string[] = Object.freeze(writableIds());
  // Measured with Sharp 0.35: webp and gif keep every frame; avif, jpeg and png stack the frames
  // into one tall image, and tiff writes them as pages, which no browser plays.
  readonly animatedFormats: readonly string[] = Object.freeze(['gif', 'webp']);

  resize(frame: Raster, req: ResizeRequest, { limits }: EngineCallOptions): Promise<Raster> {
    const input = sharp(frame.data, rasterInput(frame));
    // `fill` scales each axis by its own factor; the reduction after beforeSteps scales both by one.
    let img = (req.coverBox
      ? input.resize(req.coverBox.width, req.coverBox.height, { fit: 'outside' })
      : input.resize(req.width, req.height, { fit: req.mode === 'cover' ? 'cover' : 'fill', position: 'center' })
    ).toColorspace('srgb');
    if (req.sharpen) {
      img = img.sharpen();
    }
    return readRaster(img.timeout({ seconds: limits.processingTimeoutSeconds }));
  }

  async encode(raster: Raster, req: EncodeRequest, { limits }: EngineCallOptions): Promise<EncodedImage> {
    const { frames = 1, delay, loop } = raster.info;
    let img = sharp(raster.data, rasterInput(raster));
    if (req.background !== undefined) {
      img = img.flatten({ background: req.background });
    }
    // Raw pixels carry no timing: without the source's, an animation plays at the encoder's
    // default speed and loops once.
    const timing =
      frames > 1
        ? {
            ...(delay !== undefined && delay.length > 0 ? { delay: delayPerFrame(delay, frames) } : {}),
            ...(loop !== undefined ? { loop } : {}),
          }
        : {};
    const { data, info } = await img
      .toFormat(req.format as keyof FormatEnum, { ...timing, ...req.options } as OutputOptions)
      .timeout({ seconds: limits.processingTimeoutSeconds })
      .toBuffer({ resolveWithObject: true });
    // Keep the comment render.ts has here on Sharp reporting AVIF through its HEIF container id.
    const format = info.format === 'heif' && isAvifBuffer(data) ? 'avif' : info.format;
    return { data, format, contentType: `image/${format}`, width: info.width, height: info.pageHeight ?? info.height };
  }
}
```

```ts
/**
 * Whether a resize result has the requested size. A `coverBox` request only has to cover its box,
 * within a pixel of the computed size: Sharp's `fit: 'outside'` rounds exact halves its own way.
 */
function sizeFits(info: RasterInfo, req: ResizeRequest): boolean {
  if (req.coverBox === undefined) {
    return info.width === req.width && info.height === req.height;
  }
  return (
    Math.abs(info.width - req.width) <= 1 &&
    Math.abs(info.height - req.height) <= 1 &&
    info.width >= req.coverBox.width &&
    info.height >= req.coverBox.height
  );
}

/** A resize result the plan can rely on, or an engine contract error. */
async function resized(engine: ImageEngine, frame: Raster, req: ResizeRequest, opts: EngineCallOptions): Promise<Raster> {
  const out = await engine.resize(frame, req, opts);
  const problem =
    rasterProblem(out) ??
    (!sizeFits(out.info, req)
      ? `it is ${out.info.width}×${out.info.height}, not ${req.width}×${req.height}`
      : (out.info.frames ?? 1) !== 1
        ? `it has ${out.info.frames} frames`
        : undefined);
  if (problem !== undefined) {
    throw new ResizeSetupError(`resize: engine '${engine.id}' broke its contract: the result of resize(): ${problem}`, {
      code: 'RESIZE_ENGINE_INVALID',
    });
  }
  return out;
}

/** An encode result a row can record, or an engine contract error. `format` becomes the file extension. */
function checkEncoded(engine: ImageEngine, out: EncodedImage): void {
  const positive = (n: unknown) => Number.isInteger(n) && (n as number) > 0;
  const problem = !Buffer.isBuffer(out?.data)
    ? '`data` is not a Buffer'
    : typeof out.format !== 'string' || out.format === ''
      ? 'no `format`'
      : !/^[a-z0-9]+$/i.test(out.format)
        ? `the \`format\` '${out.format}' is not a file extension`
        : typeof out.contentType !== 'string' || out.contentType === ''
          ? 'no `contentType`'
          : !positive(out.width) || !positive(out.height)
            ? `the size ${String(out.width)}×${String(out.height)}`
            : undefined;
  if (problem !== undefined) {
    throw new ResizeSetupError(`resize: engine '${engine.id}' broke its contract: the result of encode(): ${problem}`, {
      code: 'RESIZE_ENGINE_INVALID',
    });
  }
}

/** The raster as straight alpha: itself unless its bytes are marked premultiplied. Plain JS (D8). */

  if (raster.info.premultiplied !== true) {
    return raster;
  }
  const { premultiplied: _dropped, ...info } = raster.info;
  const { channels } = info;
  if (channels !== 2 && channels !== 4) {
    return { data: raster.data, info };
  }
  const data = Buffer.allocUnsafe(raster.data.length);
  const colours = channels - 1;
  for (let i = 0; i < data.length; i += channels) {
    const alpha = raster.data[i + colours];
    data[i + colours] = alpha;
    for (let c = 0; c < colours; c++) {
      data[i + c] = alpha === 0 ? 0 : Math.min(255, Math.round((raster.data[i + c] * 255) / alpha));
    }
  }
  return { data, info };
}

export async function reduceToBox(raster: Raster, box: DecodeBox, engine: ImageEngine, opts: EngineCallOptions): Promise<Raster> {
  const frame = firstFrame(raster);
  const { width, height } = frame.info;
  if (width <= box.width || height <= box.height) {
    return frame;
  }
  // One factor, the smaller, then each side rounded: Sharp's `fit: 'outside'` up to exact halves,
  // which it can round the other way (see sizeFits). The engine's own size is kept.
  const factor = Math.min(width / box.width, height / box.height);
  return resized(
    engine,
    frame,
    { width: Math.round(width / factor), height: Math.round(height / factor), mode: 'fill', sharpen: false, coverBox: box },
    opts,
  );
}
```

```ts
// The engine of one Resizer: the host's, or the built-in Sharp engine, checked by shape (the core
// never checks `instanceof`), and what `verify()` asks of it.
const isStringList = (value: unknown): value is string[] =>
  Array.isArray(value) && value.every((v) => typeof v === 'string' && v !== '');

export function createEngine(given?: unknown): ImageEngine {
  // Only `undefined` means the default: `null` is not an engine.
  if (given === undefined) {
    return new SharpEngine();
  }
  const e = given as Partial<ImageEngine> | null;
  if (
    typeof e?.id !== 'string' || e.id === '' ||
    !isStringList(e.formats) || e.formats.length === 0 ||
    !isStringList(e.animatedFormats) ||
    typeof e.resize !== 'function' || typeof e.encode !== 'function' ||
    (e.verify !== undefined && typeof e.verify !== 'function')
  ) {
    throw new ResizeSetupError(
      'resize: `engine` is not an image engine — it needs an `id`, a non-empty `formats` list, an `animatedFormats` list, and `resize` and `encode` functions',
      { code: 'RESIZE_ENGINE_INVALID' },
    );
  }
  return e as ImageEngine;
}

/** The engine's own check, then every configured output format against its list. */
export async function verifyEngine(engine: ImageEngine, config: ResizeConfig, resizerName: string): Promise<void> {
  await engine.verify?.();
  const missing = [...new Set([...config.formats, ...Object.keys(config.encode.formats)])].filter(
    (format) => !engine.formats.includes(format),
  );
  if (missing.length > 0) {
    throw new ResizeSetupError(
      `resize: Resizer '${resizerName}' configures formats [${missing.join(', ')}] that engine '${engine.id}' does not write — it writes [${engine.formats.join(', ')}]`,
      { code: 'RESIZE_ENGINE_FORMAT_UNSUPPORTED' },
    );
  }
}
```

  > - `id` names the engine in messages.
  > - `formats` lists the ids `encode` writes. `verify()` and worker start refuse an entry of `formats` or `encode.formats` it does not list (`RESIZE_ENGINE_FORMAT_UNSUPPORTED`).
  > - `animatedFormats` lists the ids `encode` writes with every frame. Any other format gets the first frame. With `[]`, an animated source decodes one frame.
  > - `resize(frame, { width, height, mode, sharpen, coverBox }, { limits, signal })` takes one frame and resolves with one frame at exactly `width × height` (with `coverBox`: within a pixel of it, covering the box), 8-bit sRGB, 3 channels or 4 with alpha; a grey frame comes back as colour. `mode: 'fill'` puts the whole frame into that size, and `'cover'` scales to cover it and crops from the centre. An engine without a sharpener ignores `sharpen`. `coverBox` is set only on the reduction after `beforeSteps`: it is the box `width × height` was computed from, and any engine may ignore it.
  > - `encode(raster, { format, options, background }, { limits, signal })` takes one frame of 1 to 4 channels with straight alpha, or `info.frames` of them (with `info.delay` and `info.loop`) for a format in `animatedFormats`. `options` is `encode.formats[format]`. When `background` is set, flatten onto it first. It resolves with `{ data, format, contentType, width, height }`, the size of one frame. The result's `format` is the preview's file extension, letters and digits only; the row keeps the id the host configured.
  > - `verify()` is optional, and runs in `resizer.verify()` and at worker start, after the decoders'.
  >
  > Two rules the types cannot state. An engine must not write to its inputs, because the formats of one size share one raster. It must be re-entrant, because calls run concurrently, up to `concurrency`. A result of another size, or one without those fields, is `RESIZE_ENGINE_INVALID`.
  >
  > The engine is not part of `encodeSig` and declares no version. Switching engines does not regenerate stored previews; bump each pipeline's `version` to do that. An engine that animates a format other than `gif` or `webp` does not sign `animated` into that format's `encodeSig`, so after changing `animated`, bump `version` too.
  >
  > `SharpEngine.formats` lists every id Sharp's `toFormat` accepts that this build can write, aliases included.

```ts
/** A 64×48 source: the left eighth is transparent, so a flattened format needs its background. */
function sourcePng(): Buffer {
  const data = Buffer.alloc(64 * 48 * 4);
  for (let i = 0; i < 64 * 48; i++) {
    data.set([200, 30, 90, i % 64 < 8 ? 0 : 255], i * 4);
  }
  return encodePng({ data, info: { width: 64, height: 48, channels: 4 } });
}

function setup(engine: FakeEngine | undefined, config: DeepPartial<ResizeConfig> = {}, name?: string, decoder: SourceDecoder = new FakePngDecoder()) {
  const { storage, files } = memoryStorage();
  const doc: MediaLike = { id: 'm1', previews: [] };
  const resizer = new Resizer({
    ...(name ? { name } : {}),
    storage,
    media: fakeMedia({
      load: async () => doc,
      appendPreviews: async (_id: string, rows: Preview[]) => {
        doc.previews = [...(doc.previews ?? []), ...rows];
        return rows;
      },

    ...(engine ? { engine } : {}),

test('a fake engine renders every size eager, and each file is what its row says', async () => {
  const engine = new FakeEngine();

  doc.original = await resizer.uploadOriginal({ body: sourcePng(), visibility: 'private' });

  assert.equal(engine.calls.filter((c) => c.op === 'resize').length, 2);
```
