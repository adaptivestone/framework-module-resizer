# 0.4 phase F: docs and release preparation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make 0.4.0 ready for the owner to release: a shipped `UPGRADING.md` with all upgrade material, one full error table in the README, an `AGENTS.md` of at most 5,000 words, the version bump, a complete changelog and the owner's check list, each kept true by a test.

**Architecture:** Documents move and shipped code does not change. New guards read the documents: `errorTableRows()` holds the README table to `RESIZE_ERROR_CODES` and to the audited `retryable` values, `docAnchors()` holds links between documents to real files and headings, and `checkDocLinks.ts`, run by hand at release, reads a build of the docs site for links across the two repositories.

**Tech Stack:** Markdown, TypeScript with type stripping, `node:test`, Biome, npm tarball `files`, Docusaurus 3 (docs site, scratch build only).

**Spec:** `docs/design/2026-11-04-0.4.0.md`, rulings F1 to F4 and "Owner's checks". This phase has no research folder. The base is `feat/0.4-e-push` at 2bbc982, which is final.

## Rulings

```ts
// The README's `## Error codes` table, read for the guards that keep it in step with the codes and
// with the audited `retryable` values.
export interface ErrorTableRow {
  code: string;
  retryable: string; // the cell as written: `true`, `false` or —
  text: string;
}

export function errorTableRows(readme: string): ErrorTableRow[] {
  const start = readme.indexOf('\n## Error codes\n');
  if (start < 0) {
    throw new Error('README.md has no "## Error codes" section');
  }
  const end = readme.indexOf('\n### ', start + 1);
  const rows: ErrorTableRow[] = [];
  for (const line of readme.slice(start, end).split('\n')) {
    const m =
      /^\| `(RESIZE_[A-Z0-9_]+)` \| (`true`|`false`|—) \| (.*) \|$/.exec(line);
    if (m) {
      rows.push({ code: m[1], retryable: m[2], text: m[3] });
    } else if (line.startsWith('| `')) {
      throw new Error(`a row the table does not read: ${line.slice(0, 80)}`);
    }
  }
  return rows;
}
```

```ts
// The anchors GitHub gives a markdown file's headings: lower case, no character but a letter, digit,
// space, hyphen or underscore, one hyphen per space, and -1, -2 on a repeat. Fences hold no headings.
export function docAnchors(markdown: string): Set<string> {
  const seen = new Map<string, number>();
  const anchors = new Set<string>();
  for (const m of withoutFences(markdown).matchAll(/^#{1,6} (.+)$/gm)) {
    const slug = m[1]
      .toLowerCase()
      .replace(/[^\p{L}\p{N} _-]/gu, '')
      .replace(/ /g, '-');
    const n = seen.get(slug) ?? 0;
    seen.set(slug, n + 1);
    anchors.add(n === 0 ? slug : `${slug}-${n}`);
  }
  return anchors;
}

export const withoutFences = (markdown: string): string =>
  markdown.replace(/^ *```[\s\S]*?^ *```/gm, '');
```
